# 10分钟极速复现指南（评委用）

目标：在已安装 Android Studio / SDK 的前提下，约 10 分钟从空环境跑到可演示的「中央学生助手」主线，并在过程页点开留痕。首次安装 SDK 或创建模拟器不计入这 10 分钟。

仓库：[MIMIMIXIAOBAI/Student-Spending-Bill](https://github.com/MIMIMIXIAOBAI/Student-Spending-Bill)（须保持 Public 或向评委开放访问）  
包名：`com.campusbill.app` · 纯 Java + Room · 本地路径约定：`E:\AI\Student Spending Bill`

交赛材料总清单见 [SUBMISSION-CHECKLIST.md](SUBMISSION-CHECKLIST.md)。环境变量模板见 [env.example](env.example)。

## 1. 环境配置

| 项 | 要求 |
|---|---|
| Android Studio | Narwhal 或更新（内含 JDK 17） |
| SDK | Platform API 37 + Build-Tools；模拟器建议 API 29+、Graphics = Hardware |
| Gradle | 使用仓库自带 Wrapper（无需单独安装） |
| 本机文件 | 根目录创建 `local.properties`，写入 `sdk.dir=...`（该文件已 gitignore） |

```powershell
git clone https://github.com/MIMIMIXIAOBAI/Student-Spending-Bill.git
cd "Student-Spending-Bill"
# 按 docs/assistant/env.example 写入 local.properties 后：
.\gradlew.bat assembleDebug installDebug
```

或用 Android Studio 打开仓库根目录，Sync 后 Run。不要把 DeepSeek Key 写进任何仓库文件或 `gradle.properties`。

## 4. 首次启动：DeepSeek Key 向导

1. 打开应用，在记账首页「智能消费账单助手」下方找到常驻大球（已替换原「AI消费建议」卡片；白卡左右各留 16dp，高度约 260dp、上限 300dp）。位移不超过 12dp 的轻点进入中央助手对话页（现有 `AiChatActivity` 扩展，仍为竖屏）；上下滑动不要判成进入。
2. 按向导粘贴 **DeepSeek API Key**。密钥写入本机 Keystore，仅本机有效。
3. 向导应给出「测通 / 失败」结果后再进入对话。失败时文字状态为「出错」（密钥失败、余额不足、网络错误），检查网络与 Key，不要改仓库配置。

默认接口与模型以向导内预填为准（账本阶段曾默认 `https://api.deepseek.com/chat/completions`、`deepseek-chat`，以当前向导文案为准）。

## 5. 演示主线（请按顺序说）

建议先确保本机 Room 里已有本周食堂相关账单（可用「记一笔」或导入；评测机可用仓库 `模拟账单/`）。本周按周一至周日，日期 `YYYY-MM-DD`。用户问「当月」时，按首页折线图当前选中的年月查询，不要用切换前的数据。

文字状态共四档，独立可见：**思考 / 调用工具 / 等待确认 / 出错**。确认卡只出现在「等待确认」。回复为流式字符输出（硬指标）；思考过程可可视化。Emotion Ball 不能替代文字状态。按已拍板约定：记账首页「智能消费账单助手」下用常驻大球替换「AI消费建议」卡片（白卡左右 16dp，高度约 260dp、上限 300dp），卡上滑动时视线跟随，位移不超过 12dp 的轻点进入对话页，不要把上下滑判成进入。首页大球与对话页的球均可用手机姿态（旋转向量/陀螺仪）驱动视线，调用 `setGaze` 看向倾斜方向：只在空闲 `02`、且页面可见时生效；进后台或离开当前页就停，继续 `setActive(false)`。球在按住说话 `35`、思考 `30`、流式出字 `39`、调用工具 `32`/`40`、等待确认 `03`、出错 `34`、成功 `33` 和报数 `19`（含回 `02` 前的 1.5 秒）时不激活，表情一开始就把视线约 400ms 收回中心。相对握持姿态偏转不足 8° 当作微抖，不驱动；达到 12° 后用 `setGaze` 看向倾斜方向，约 30° 看满（±1），回落到 8° 以内再经 400ms 回正（与手指滑动松开一致）。手指正在滑动跟随时触摸优先；幅度不够时仍按现有点击/滑动跟随。不新增加表情，不另开设置开关。对话页留下球面板，默认高度约占屏幕的三分之一，把下部留给对话，不要再做大面板；不要改回顶栏小圆球。键盘或确认卡出现时仍压到最低 160dp，不能挡住状态行和确认卡，也不能挤掉流式输出。打字弹出键盘时，输入栏和正在输入的内容必须完整留在键盘上方，对话列表上收，状态行钉在输入栏上方，确认卡也不能被盖住；窗口用 `adjustResize`，不要让键盘直接叠在输入框上。表情必须用 Emotion Ball 官方两位 `emotionId` 调用 `setEmotion('35')` 这类字符串，不要再用 `listening` / `pleased` 等自造名；未知 ID 会回退到 `02` 待机放空。只使用已有 32 个编号（`00`–`07`、`10`–`21`、`30`–`41`），完整陈列见 [Emotion Ball 表情馆](https://sam70361.github.io/aora-bot/)。对照：空闲 `02` 待机放空；按住说话（倾听）`35` 等待输入；松开进入思考 `30` 思考中（并走现有「思考」状态）；流式出字 `39` 输出回复；回复结束（成功/激动）`33` 任务完成，约 1.5 秒后回 `02`；查询报出数字用更克制的 `19` 满意，1.5 秒后回 `02`；调用工具 `32` 处理中忙碌，查账单也可用 `40` 检索资料；等待确认 `03` 好奇；出错（含识别失败、无麦克风权限）`34` 出错，不要停在 `35`；用户取消确认回 `02`，不要用失落。输入栏右侧、发送按钮左侧为红色圆形麦克风按钮：视觉直径 36dp，热区 44dp，垂直居中，与发送按钮间距 8dp；白麦克风图标 18dp，填充 `#FF3B30`，无描边。按下开始收音、球切 `35`，圆钮缩到 0.92、填充改为 `#D63027`，外加 3dp、30% 透明的 `#FF3B30` 光圈，约 120ms，不弹键盘；按住期间球保持 `35`。交互和风格跟现有按钮统一，必须有按下反馈。只动语音，四档状态和确认卡都不变，继续用现在的中文小模型，不换大模型。语音路径：按下前先查已安装的识别服务（荣耀/华为优先，再讯飞、百度、Google），在线优先，禁止再默认离线；没有可用服务，或系统识别全部失败后，立刻改走按住 `AudioRecord` 录音 + 应用内开源 Vosk（Apache-2.0，中文小模型 `vosk-model-small-cn-0.22` 构建时下载进 APK，不提交压缩包）。首次进入对话页时后台解压模型。第一次麦克风授权通过后，若手指还按着就直接开始听，不要再按一次；拒绝则状态行「无麦克风」。当前调试包为 `C:\Users\ZXM\Desktop\测试v0.8.1.apk`（Trae 称 118,122,128 字节，SHA256
