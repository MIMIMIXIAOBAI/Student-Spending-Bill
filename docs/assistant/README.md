# 中央学生助手 · Prompt 与协议（v0.1 草稿）

- **版本**：`v0.1`（2026-11-10，Asia/Shanghai）
- **范围**：比赛项目第一版。只接通三件事：查账/记账主线、日记作经确认的上下文、一个娱乐工具（今日运势/情绪晴雨表；塔罗只作为运势下的玩法）。
- **仓库落点**：本目录。过程日志见 `process/`。演进记录同时接到仓库根目录 `prompt_evolution.md`、`Promat历史/`。
- **实现约束**：不改账本数据模型；助手只经工具适配器访问 `BillDao` / `BillEntity`。密钥不进仓库。本文档只定义 Prompt / schema / 协议，不改 Java（由工程侧接入）。

| `session.v0.1.md` | 历史会话、上下文占用百分比与要点交接（已冻；不另开版本号） |

修订时递增版本号（v0.2…），旧文件保留以便评委复现。

文字状态四档：思考、调用工具、等待确认、出错（失败态）。v0.1 草稿在合入前已按评估页补上「出错」，不另开版本号。

按 2026-11-10 再更正：球必须使用 Emotion Ball 官方 32 个 `emotionId`：空闲 `02`、思考 `30`、流式出字 `39`、成功 `33`、查询报数 `19`、工具 `32`（查账可用 `40`）、等待确认 `03`、出错 `34`。禁止传自造情绪名。详见 `emotion-map.v0.1.md`。问「当月」「本月」时跟首页折线图当前选中月份走，见 `SYSTEM_PROMPT.v0.1.md` 与 `tools.schema.v0.1.json` 的 `chart_month`。对话页球约占屏高三分之一，键盘或确认卡时仍压到 160dp。用户真机认为语音效果不好，主管已冻结：**语音输入整段取消**（红圆麦克风、Vosk、按住识别均不再作为产品能力，不再改 `测试v0.8.1` 的语音；倾听 `35` 不再使用）。本包只做历史对话，见 `session.v0.1.md`：切页或退出不新开会话，会话存本地 Room；右下角按实际 token / 模型窗口显示占用百分比；约 80% 且本轮回复结束后只预存要点、不自动切换；用户新建对话时再带入；约 95% 或本轮请求会超窗时才自动开下一场。左侧用抽屉新建/切换/重命名/删除历史。球、陀螺仪、月份同步本包不动。新包路径待工程交付。
