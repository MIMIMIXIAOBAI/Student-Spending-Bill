# 情绪与状态映射 v0.1

文字状态仍是主体，取值只能是：思考、调用工具、等待确认、出错。Emotion Ball（WebView，上游 `sam70361/aora-bot` 的 **emotion-ball 分支**，共 32 种官方表情）**不再默认关闭，也不再用顶栏「球/关」开关**。该造型不可商用，许可在关于页署名 aora-bot；Prompt 不重复展开法律文本。

球是视觉陪伴，不能替代四档文字状态、流式输出或确认卡。不新增第五档文字状态。

表情必须调用官方两位 `emotionId`，例如 `ball.setEmotion('30')` 或 `ball.handleAIMessage('{"emotionId":"30"}')`。**禁止**把 `listening`、`pleased`、`concerned` 这类自造名传给引擎：未知 ID 会回退到 `02` 待机，看起来就像表情逻辑不对。编号以 emotion-ball 分支 `emotion-ball/js/emotions.js` 为准，不要使用后来 Aora Bot 才有的 `22` / `25` / `46` 等扩展号。

## 占位（已冻，2026-11-10）

旧约定「只改 AI 对话页、记账首页不放球」已作废。对话页「改顶栏约 64dp 小球」同步作废，仍用球面板。

### 记账首页

- 在「智能消费账单助手」下方，用常驻大球替换原「AI消费建议」卡片。
- 白卡左右各留 16dp；高度约 260dp，上限 300dp；球在卡内居中，尽量铺满。
- 在卡上滑动时，把触点相对球心归一化到 `[-1, 1]`，调用 `ball.setGaze(nx, ny)`；松手后约 400ms 回到正视。
- **位移不超过 12dp 的轻点进入 AI 对话页**，不要把首页上下滑误判成进入。不在首页展开完整对话。
- 首页大球默认 `02` 待机放空。

### AI 对话页

- 只改对话页，首页大球不动（白卡约 260dp，上限 300dp），仍用原来的白卡。
- 球留下，仍用球面板，默认高度约占屏幕的三分之一，下部留给对话，不要再做大面板，也不要改回顶栏小圆球。
- 键盘弹出或出现确认卡时，球面板压到 160dp 后不再往下，160dp 是硬下限。若压到 160dp 仍可能挡住，优先露出输入栏、状态行、确认卡和流式回复，球停在 160dp，靠 `adjustResize` 把输入栏顶在键盘上方。不要做已经取消的顶栏 64dp 球，首页大球也不要缩小。
- 对话页球容器全透明：去掉白底、描边和方形阴影，只留球体。球旁边的空白要能点到下面的消息，也能继续滑动。
- 历史上滑时，列表延伸到顶栏下方、从球后面过去，不要被方框硬切。渐隐从球体下沿向上 48dp、全宽线性：下沿完全透明，向上 48dp 处用对话页现有页底浅灰（本包为 `#F2F2F7`）到完全不透明，不要另起颜色，也不要出现一条横档。球面本身不透明，字不透过球；球两侧透明，可以露字。键盘或确认卡把球压到 160dp 时，这 48dp 跟着球体下沿走，不要跟着旧方框走。只改对话页。
- 四档文字状态只在出现「思考 / 调用工具 / 等待确认 / 出错」时显示在输入栏上方，高 32dp；空闲时不占位。确认卡只出现在「等待确认」，并留在消息流里。

## 视线跟随

仍用 aora-bot `emotion-ball` 的 WebView，由应用计算坐标，不让模型输出视线字段。首页大球与对话页球面板均适用。

### 触控

- 把触点相对球心归一化到 `[-1, 1]`，调用 `ball.setGaze(nx, ny)`。
- 松手后约 400ms 回到正视。
- 页面不可见或进入后台时调用 `setActive(false)` 停帧，并停止读取传感器。

### 姿态跟随（用户新增，待主管确认后落地）

读取手机陀螺仪 / 姿态传感器，把设备倾斜方向映射到 `setGaze(nx, ny)`（同样归一化到 `[-1, 1]`），让球看向倾斜的方向。用户转动、倾斜手机时，注视同步变化。

- **仅在中 / 大幅度摆动时激活**，小幅抖动忽略（具体角度阈值由设计补一版后写入，工程不要对轻微晃动跟手）。
- **当前表情被占用时不激活**：仅当球处于 `02` 待机放空时才跟姿态；思考 `30`、倾听 `35`、工具 `32`/`40`、等待确认 `03`、流式出字 `39`、成功 `33`、报数 `19`、出错 `34` 等占用态一律不启用，以免打断正在进行的表情。
- 正在触控跟随时，以触控为准，不叠加姿态。
- 不新增文字状态，也不让模型输出姿态字段。

## 语音输入（已取消并冻结，2026-11-10）

用户真机测试后认为语音效果非常不好，主管已冻结：**取消语音输入**。输入栏只保留输入框和发送，去掉红圆麦克风按钮；系统识别与 Vosk 离线回退、按住边识别、输入栏预览均不再作为产品能力，也不再改 `测试v0.8.1` 的语音。倾听表情 `35` 不再使用。四档文字状态不变。以下为取消前的规格，只作演进留痕，不要再按它实现或测试。

### 取消前的规格（已作废）



识别在应用侧完成，不新增工具、也不新增第五档文字状态，也不让模型输出识别字段。麦克风按钮在输入栏右侧、发送按钮左侧，垂直居中，间距 8dp。视觉直径 36dp，热区 44dp。默认填充 `#FF3B30`，白色麦克风图标 18dp，无描边。交互和风格与现有按钮统一。

系统 `SpeechRecognizer` 不是唯一引擎。按下前先穷举设备上的识别服务并打日志：有则在线优先走系统识别（禁止默认再加 `EXTRA_PREFER_OFFLINE`），已安装的服务都要试到（荣耀/华为优先），`NETWORK`、`AUDIO`、超时也可以换引擎；未就绪不得 `stopListening`，错误不得吞掉。没有可用服务，或系统识别全部失败时，立刻改走按住 `AudioRecord` + 应用内离线识别。离线引擎用开源 **Vosk**（Apache 2.0，中文小模型打包进应用；关于页和第三方说明署名）。不要接讯飞等闭源 SDK，也不要让用户去装 Google。首次进入对话页时后台解压模型，避免第一次按下卡很久。第一次授权通过后，若手指还按着就直接开始听，不要再按一次。

- **按下**：开始收音，不弹键盘；约 120ms 内圆钮缩到 0.92，填充改为 `#D63027`，外加 3dp、30% 透明的 `#FF3B30` 光圈。球切到 `35` 等待输入（官方 Listening）。此时不要改四档文字状态。
- **松开**：约 120ms 恢复常态。将识别出的文字作为**一条**用户消息发给助手，球切到 `30` 思考中，并走现有的「思考」状态。
- **流式正文输出时**：球可切到 `39` 输出回复。
- **回复结束**：球切到 `33` 任务完成（官方 Done，含短暂庆祝），约 1.5 秒后再回到 `02` 待机放空。不要长时间撒花挡文字。
- **识别失败或没有麦克风权限**：用现有「出错」行提示，并写清原因（无麦克风权限 / 未识别到内容 / 引擎不可用等），球切到 `34` 出错，不要停在 `35`。

### 长句识别（取消前曾冻结，现随语音一并作废）

`测试v0.8` 真机：短句已能识别并发送，稍长的话会失败。长句预览包请装 `C:\Users\ZXM\Desktop\测试v0.8.1.apk`（[`072fc1c`](https://github.com/MIMIMIXIAOBAI/Student-Spending-Bill/commit/072fc1c72f5a6baf55d7edde916f2fd1c8dba05e)），不要再用 v0.8。继续用现有 Vosk 中文小模型，不换大模型。按住时边说边识别，按停顿断句；按住期间球保持 `35`，已识别的字只出现在输入栏里作预览，方便确认长句有没有被收到。松手仍自动把整段作为**一条**用户消息发出，不要中途拆成多条，也不要再按发送；随后球再切到 `30`。识别失败走出错 `34`，预览清掉，球不要停在 `35`。只动语音，四档状态和确认卡都不变；效果不好就整段撤回。真机长句效果仍待确认。

|---|---|---|---|---|
| （按住说话中，无新文案档） | — | `35` | 等待输入 | 仅球表情；不占四档文字状态 |
| thinking | 思考 | `30` | 思考中 | 流式思考；语音松开发出后也走这一档 |
