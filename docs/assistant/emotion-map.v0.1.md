# 情绪与状态映射 v0.1

文字状态是主体。Emotion Ball（WebView，上游 `sam70361/aora-bot` 的 emotion-ball 造型）必须：**克制、默认可关闭、不占中屏**。该造型不可商用，许可标注由文档/许可页负责，Prompt 不重复展开法律文本。

## 进行中状态（与界面文案一致）

| 协议状态 | 界面文案 | 球（若未关闭） | 说明 |
|---|---|---|---|
| thinking | 思考 | 轻微思考/专注，低动效 | 流式思考 |
| tool | 调用工具 | 短暂「工作」态 | 查询、运势、申请日记 |
| awaiting_confirm | 等待确认 | 等待/凝视，不欢快跳动 | 确认卡可见时 |

## 结果态（球可选，不要另做一套文案抢对话）

| 场景 | 建议情绪 | 不要做 |
|---|---|---|
| 查询成功并报出数字 | calm / 轻点头 | 大庆祝动画挡文字 |
| 查询为 0 | calm / 中性 | 沮丧或责备用户 |
| 记账确认并回读成功 | pleased，很快回到 idle | 长时间庆祝 |
| 用户取消确认 | idle | 表现失望 |
| 日记未授权 | idle，不追问第二次以上 | 假装已读日记 |
| 运势 | light / 轻松 | 改成占卜独立页 |
| 工具失败或 Key 未配 | concerned，文案说明原因 | 假装成功 |

## 映射来源（应用计算，不让模型乱设情绪）

优先由客户端根据状态机映射，模型不必输出情绪字段。若以后要加可选字段，仅允许：

`idle | thinking | tool | awaiting_confirm | pleased | calm | concerned | light`

禁止新增恐怖、卖萌过度、持续闪烁等干扰评审阅读的状态。
