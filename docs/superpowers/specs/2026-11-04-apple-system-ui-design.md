# Apple × 轻点缀 · 全 App 系统 UI 升级设计

日期：2026-11-04  
项目：学生消费账单（com.campusbill.app）  
分支建议：`feat/ui-tokens-p0`（或新建 `feat/apple-system-ui`）  
状态：已定稿，待实现

## 目标

把当前「奶油页底 + 浅描边卡片 + 糖果材质残留」升级为 **Apple 系统感为主、极淡粉彩只点缀** 的统一视觉与交互，覆盖全 App 组件层，并加上按压缩放与系统感底栏。

不再遵循 `Promat历史` / 旧 UI 提示词中的 Y2K 半融合约束。

## 已确认决策

| 项 | 选择 |
|----|------|
| 风格 | Apple × 轻点缀 |
| 范围 | 全 App + 交互（按压缩放、分组列表、系统感导航） |
| 底栏 | iOS Tab：白底细顶线、选中色、图标+短标签 |
| 卡片 | Grouped：浅灰页底上的白卡，靠间距分组、几乎无描边 |
| 主按钮按压 | 轻微缩放 ≈0.96，松手回弹 |
| 主 CTA 色 | **天空蓝 → 淡粉渐变**（不再锁死纯色校园蓝 `#2F6FED` 作唯一填充） |
| 路径 | A：全 App 系统组件层换肤 |

## 视觉 tokens

### 页底与表面

- 页底：`#F2F2F7`（系统 grouped 灰），去掉奶油渐变 / Y2K 铺底 drawable
- 卡片：`#FFFFFF`，圆角 16–20dp，**无描边**（或仅在极必要时用 `#E5E5EA` ≤1dp，默认不用）
- 卡片间距：垂直 12–16dp 分组；内边距 16dp

### 文字

- 主文：`#1C1C1E`
- 次文：`#8E8E93`
- 说明 / hint：`#AEAEB2`

### 主色与点缀

- 主 CTA 填充：水平渐变，天空蓝 → 淡粉（建议起止约 `#5BB8F5` → `#FFB4D6`，实现时可微调但保持同方向）
- 选中 / 链接 / 底栏选中：取渐变偏天空蓝一侧的实色（约 `#5BB8F5` 或相近），避免整栏刷渐变文字难读
- 粉彩：仅图表序列点、AI 用户气泡极淡粉；**面板、主按钮以外的控件不再铺糖果玻璃 / 高光 layer-list**

### 语义色（保留）

- 收入绿、支出红/警示：保持现有语义，略降饱和以贴合系统感即可

## 组件规范

### 主按钮

- 形状：胶囊（`radius_pill`）
- 填充：天空蓝→淡粉渐变；白字
- 禁止：顶部高光 layer-list、粘土描边、双层错位描边
- 按压：`scaleX/Y = 0.96`，约 100ms ease-out；松手回弹

### 次要按钮

- 浅灰底（`#E5E5EA` / `#EFEFF4`）或纯文字按钮
- 无喧闹描边

### 卡片 / 分组列表

- Grouped 白卡；列表行之间用 0.5dp `#C6C6C8` 细分隔（或系统 hairline）
- 连续设置型区块可用同一白卡内部分组

### 输入框

- 默认：浅灰底 `#EFEFF4`，圆角 12–14dp
- 聚焦：细环用天空蓝一侧实色即可

### Chip / 分段

- 未选中：灰字
- 选中：浅天空蓝底或白底 + 选中蓝字；不用高饱和糖果 pill

### 底部导航

- 白底 + 顶部 0.5dp 分割线
- 图标 + 短中文标签
- 选中：天空蓝一侧实色；未选中 `#8E8E93`

## 交互

- 可点主按钮、可点卡片：按下 scale ≈0.96
- 不做整页过渡大改；优先统一触感

## 范围与非目标

### 做

- 更新 `colors.xml` / `dimens.xml` / 共用 drawable（`bg_page*`、`bg_card*`、`bg_button_*`、`bg_input*`、chip、底栏相关）
- 关键页面（首页、记一笔、图表、日历、导入、AI、历史）跟进同一套 token，去掉旧奶油/Y2K 铺底引用
- 按压缩放 helper（Java 侧 touch listener 或共用 style）挂到主 CTA 与关键可点卡

### 不做

- 信息架构 / 导航目的地大改
- 换图标库
- 重写图表库本身（只改表面色与容器）
- 继续执行旧 Y2K 半融合提示词

## 验收

1. 任意主页面：浅灰页底 + 白卡分组，无奶油渐变铺满、无卡片粗描边
2. 「手动记一笔」等主 CTA：天空蓝→淡粉渐变胶囊，无错位高光边；按下有轻微缩放
3. 底栏：白底细顶线，选中为天空蓝系，图标+短标签
4. 粉彩不出现在面板大面积背景上
5. Debug 构建可安装，无资源引用断裂

## 实现备注

- 旧 `color_primary #2F6FED` 可保留为兼容别名或改为天空蓝实色，但 **主按钮必须用渐变 drawable**，不以纯校园蓝为唯一视觉主填充
- 渐变 drawable 用 `shape` + `gradient`；按压缩放用代码动画，避免再叠 layer-list 高光
- 提交信息建议：`feat(ui): Apple system grouped surfaces + sky-pink CTA`
