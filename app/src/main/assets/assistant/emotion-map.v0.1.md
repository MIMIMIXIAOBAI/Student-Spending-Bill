# 情绪与状态映射 v0.1

文字状态仍是主体，取值只能是：思考、调用工具、等待确认、出错。Emotion Ball（WebView，上游 `sam70361/aora-bot` 的 emotion-ball 造型）**不再默认关闭，也不再用顶栏「球/关」开关**。该造型不可商用，许可在关于页署名 aora-bot；Prompt 不重复展开法律文本。

球是视觉陪伴，不能替代四档文字状态、流式输出或确认卡。不新增第五档文字状态。

## 占位（已冻，2026-11-10）

旧约定「只改 AI 对话页、记账首页不放球」已作废。对话页「改顶栏约 64dp 小球」同步作废，仍用球面板。

### 记账首页

- 在「智能消费账单助手」下方，用常驻大球替换原「AI消费建议」卡片。
- 白卡左右各留 16dp；高度约 260dp，上限 300dp；球在卡内居中，尽量铺满。
- 在卡上滑动时，把触点相对球心归一化到 `[-1, 1]`，调用 `ball.setGaze(nx, ny)`；松手后约 400ms 回到正视。
- **位移不超过 12dp 的轻点进入 AI 对话页**，不要把首页上下滑误判成进入。不在首页展开完整对话。

### AI 对话页

- 球留下，仍用球面板；键盘弹出或出现确认卡时，压到最低 160dp，不能挡住状态行和确认卡，也不能挤掉流式输出。
- 四档状态仍固定在输入栏上方；确认卡只出现在「等待确认」，并留在消息流里。

## 视线跟随

仍用 aora-bot `emotion-ball` 的 WebView，由应用计算坐标，不让模型输出视线字段。首页大球与对话页球面板均适用。

- 把触点相对球心归一化到 `[-1, 1]`，调用 `ball.setGaze(nx, ny)`。
- 松手后约 400ms 回到正视。
- 页面不可见或进入后台时调用 `setActive(false)` 停帧。

## 语音输入（对话页）

识别在应用侧完成，不新增工具、也不新增第五档文字状态。按钮在输入栏右侧：按住说话，松开发送。

- **按下**：开始收音，球切到「倾听」（`listening`）。此时不要改四档文字状态。
- **松开**：结束收音。识别出的文字作为一条用户消息发出，球切到「思考」，并走现有的「思考」状态。
- **回复结束**：球切到「成功/激动」（`pleased`），约 1.5 秒后再回到 `idle`。
- **识别失败或没有麦克风权限**：用现有「出错」行提示，球切到 `concerned`，不要停在倾听。

## 进行中状态（与界面文案一致）

| 协议状态 | 界面文案 | 球 | 说明 |
|---|---|---|---|
| （按住说话中，无新文案档） | — | listening / 倾听 | 仅球表情；不占四档文字状态 |
| thinking | 思考 | 轻微思考/专注，低动效 | 流式思考；语音松开发出后也走这一档 |
| tool | 调用工具 | 短暂「工作」态 | 查询、运势、申请日记 |
| awaiting_confirm | 等待确认 | 等待/凝视，不欢快跳动 | 确认卡可见时；对话页球面板压到不低于 160dp，不挡确认卡 |
| error | 出错 | concerned，低动效 | 密钥失败、余额不足、网络错误，以及语音识别失败或无麦克风权限；说明原因后停在这一档，不加新页面；球不要停在倾听 |

## 结果态（不要另做一套文案抢对话）

| 场景 | 建议情绪 | 不要做 |
|---|---|---|
| 查询成功并报出数字 | calm / 轻点头 | 大庆祝动画挡文字 |
| 查询为 0 | calm / 中性 | 沮丧或责备用户 |
| 记账确认并回读成功 | pleased，很快回到 idle | 长时间庆祝 |
| 回复结束（含语音发出后的完整回复） | pleased / 成功激动，约 1.5 秒后回到 idle | 长时间庆祝、挡文字 |
| 用户取消确认 | idle | 表现失望 |
| 日记未授权 | idle，不追问第二次以上 | 假装已读日记 |
| 运势 | light / 轻松 | 改成占卜独立页 |
| 工具失败、密钥失败、余额不足、网络错误、语音识别失败、无麦克风权限 | 文字状态为「出错」；球用 concerned | 假装成功、另开错误页、停在倾听 |

## 映射来源（应用计算，不让模型乱设情绪）

优先由客户端根据状态机映射，模型不必输出情绪字段。若以后要加可选字段，仅允许：

`idle | listening | thinking | tool | awaiting_confirm | error | pleased | calm | concerned | light`

禁止新增恐怖、卖萌过度、持续闪烁等干扰评审阅读的状态。
