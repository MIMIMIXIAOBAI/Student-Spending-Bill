# 意图控制与反例话术 v0.1

第一版以**工具调用**为主，不扩展成新 App。本地已有 `IntentMatcher`（预算/总额/分类/排行/建议/帮助）可继续服务旧的离线回复；中央助手在线路径按下表走。

## 优先级（高 → 低）

1. **查账**（`query_spend`）：凡是涉及账单或消费的问题都先走这一步，包括「这周/今天/本月/一共花了多少」「食堂花了多少」「分类/商户合计」「我是不是花多了」「导入的那些账单」「整体习惯/消费建议」。用户指定了时间就按现有区间查；没指定、或问历史/整体习惯/消费建议时用 `period=all`。必须查到含导入和手动记录在内的本机 Room 账本，与记账页同一本账。合计和分类汇总要完整，明细过多可以截断。过程只走「调用工具」和表情 `32`（查账也可用 `40`），不弹确认卡。查不到就在回复里说明没有匹配数据。应用侧：若本轮还没成功查到账，不要把带数字的回复直接给用户。在线助手路径不得改走旧的离线 `IntentMatcher` 来回答花销。
2. **记账**（`propose_add_bill` → 确认卡 → 回读）：「记一笔」「午餐 18 元」。与查账同句出现时：先查再提议记账。
3. **日记上下文**（`request_diary_context`）：仅打招呼或调语气；先确认。
4. **运势**（`daily_fortune`）：主线演示后再用；不抢记账。
5. **超出范围**：礼貌拒绝并拉回上述能力。

## 演示脚本对齐

| 用户说法 | 期望 |
|---|---|
| 这周食堂花了多少？ | 调用 `query_spend`：`period=this_week`，并筛食堂（`merchant_contains=食堂` 和/或 `category=食堂`）。用工具结果回答，不估数。 |
| 当月 / 本月花了多少？ | 调用 `query_spend`：`period=chart_month`，区间为首页折线图当前选中年月的 1 号至月末（以应用注入的 `chart_month` 为准），不要按系统日历本月或切换前的数据回答。 |
| 一共花了多少 / 导入的账单怎么样 / 我是不是花多了 / 整体习惯或消费建议（未指定日期） | 先调用 `query_spend`：`period=all`（含导入和手动记下的全部记录），合计和分类汇总要完整，明细可截断；用工具结果回答。过程为「调用工具」，球为 `32` 或 `40`，不弹确认卡。没有匹配数据就在回复里说明，不编、不估。 |
| 再记一笔今天午餐 18 元 | `propose_add_bill`：date=今天，amount=18，remark/merchant 含午餐，分类建议食堂或餐饮。状态进入「等待确认」。 |
| 确认写入后 | 用回读的 id/日期/金额/分类/商户核对一句。 |
| 再问一句运势 | 只调 `daily_fortune`，证明会调度第二类工具。 |

## 应做

- 信息不足时最多问 1–2 个关键缺口（例如没说金额）。
- 查询为空时直接在回复里说明没有匹配数据，不要编示例账单冒充真实数据。查账不弹确认卡。
- 确认卡字段与将要写入的字段一致。

## 反例（禁止）

| 反例 | 正确做法 |
|---|---|
| 不查工具，口算或编「大概花了 80」 | 先 `query_spend` |
| 涉及账单却只凭对话印象或上一会话要点回答 | 先 `query_spend`，只用本轮工具返回 |
| 只查手工记的几笔，漏掉用户导入的历史账单 | `query_spend` 必须覆盖同一份 Room 账本（含导入） |
| 未指定时间，或问历史/整体习惯/消费建议，却只查本周或当月 | 用 `period=all` |
| 查账时弹出确认卡，或新增第五档文字状态 | 只走「调用工具」和表情 `32`/`40`，查不到就在回复里说明 |
| 本轮还没成功查到账，就把带数字的回复给用户 | 应用侧卡住，等 `query_spend` 成功后再出数字 |
| 「已经帮你记下了」但用户还没点确认 | 停在等待确认 |
| 擅自把日记内容写进回答 | 先 `request_diary_context`，未确认则不引用 |
| 把塔罗做成第二个娱乐入口或独立流程 | 仅 `daily_fortune` + `tarot_lite` |
| 要求用户再配 OpenAI/其他厂商 Key | 只走 DeepSeek Key 向导（由 App 处理） |
| 主动推销横屏、八个侧边栏、独立日记/随手记 | 说明第一版不做 |
| 把工作区或历史账单文件当成本期数据 | 只用本轮工具返回 |
| 用户已在折线图切到某月，仍按日历本月或旧月份答「当月」 | 用当前 `chart_month` 再查 `query_spend` |

## 推荐拒话语术（可微调）

- 「记账要先请你在卡片上确认，我还没有写入。」
- 「日记要先经过你同意我才能用来打招呼，这一轮我先不引用。」
- 「第一版娱乐只保留今日运势；塔罗如果要玩，也只是运势里的一种说法。」
- 「我查不到这笔数，需要先看账本查询结果，不能估。」
- 「我先查一下你账本里的记录（包括导入的），再根据查到的结果回答。」
